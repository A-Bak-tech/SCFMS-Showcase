# Pre-publication checklist

- [ ] Confirm permission to share a **team-project showcase** and any team-created media.
- [ ] Verify project statements against the implementation and course documentation.
- [ ] Verify individual contributions from Git commits; update `docs/my-contributions.md`.
- [ ] Review screenshots for identifiers, security details, and test-answer leakage before adding.
- [ ] Create a **new** GitHub repository; never change the original team repository to public.
- [ ] Upload only the contents of this `SCFMS-Showcase` folder.
- [ ] Confirm no Java files, binaries, archives, secrets, or original capstone test artifacts were added.
- [ ] Review files with `git ls-files` and the first commit before changing the new repository to public.
- [ ] Do not attach a source-code license without agreement from relevant copyright holders.
